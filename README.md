# JForce SQL Task

## Project
Employee Management and Payroll Database using MySQL Stored Procedures.

## Database
Database Name: `employee`

## Stored Procedures

1. `GetEmployeeSalaryReport`
   - Shows active employees based on department and minimum salary.

2. `CalculateEmployeeSalary`
   - Calculates HRA, DA, PF and Net Salary.

3. `EmployeeSalaryGrade`
   - Assigns salary grade A, B or C based on basic salary.

4. `GetDepartmentSummary`
   - Shows total employees, average salary, highest salary, lowest salary and total salary expenditure.

## Files

- `database.sql` - Database, table and sample employee data.
- `procedures.sql` - All stored procedures.

## Technology

- MySQL
- SQL Stored Procedures
- MySQL Workbench
